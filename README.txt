Blissers — clickable prototype

Open index.html in any browser (double-click it). There is nothing to install.
Keep the folder together, and stay online while you look: the prototype loads
its fonts and styling from the web, and unplugged it renders as plain text.

There are 40 screens. The links and buttons work;
the data is stand-in data, so nothing you type here is saved anywhere.

This is a prototype of how the app looks and moves, not the finished product.
